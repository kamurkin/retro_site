# 🕰️ Retro Site — Персональный сайт в стиле интернета 2000-х

Персональный сайт в эстетике раннего интернета (2000–2005 годы), созданный на Rust + Leptos + WebAssembly.

## 📸 Скриншоты

Сайт оформлен в стиле старых персональных домашних страниц:
- Голубой, синий, серебристый и белый цветовая гамма
- Градиенты, рамки, тени и глянцевые кнопки
- Пиксельные декоративные элементы
- Анимации при наведении
- Шрифт в стиле Windows XP (MS Sans Serif / Tahoma)
- Таблицы, панели и блоки с характерным дизайном старых сайтов

## 🛠 Технологии

- **Rust** — основной язык программирования
- **Leptos 0.5** — UI фреймворк для WebAssembly
- **WebAssembly** — целевая платформа (`wasm32-unknown-unknown`)
- **Trunk 0.22.1** — сборщик и dev-сервер
- **HTML5 + CSS3** — оформление (без внешних CSS-фреймворков)
- **JavaScript** — не используется (всё на Rust/Leptos)

## 🚀 Быстрый старт

### Предварительные требования

1. **Rust** — [установите rustup](https://rustup.rs/)
2. **Цель WebAssembly**:
   ```bash
   rustup target add wasm32-unknown-unknown
   ```
3. **Trunk** — сборщик для Rust/WASM:
   ```bash
   cargo install trunk
   ```

### Запуск в режиме разработки

```bash
cd c:\Games\retso_site\retro_site
trunk serve
```

Сайт будет доступен по адресу: **http://127.0.0.1:8080**

### Сборка для продакшена

```bash
cd c:\Games\retso_site\retro_site
trunk build --release
```

Готовые файлы будут в папке `dist/`.

## 🎨 Особенности дизайна

- **Цветовая палитра**: `#0000EE` (ссылки), `#000080` (заголовки), `#4169E1` (панели), `#C0C0C0` (боковая панель), `#FFFFFF` (фон контента)
- **Градиентный фон**: от тёмно-синего к белому
- **Глянцевые кнопки**: с градиентом, тенью и эффектом нажатия
- **Эффекты наведения**: смена цвета, рамка `inset`, анимации
- **Таблицы**: с двойной рамкой заголовков, чередованием строк, подсветкой при наведении
- **Счётчик посещений**: в стиле старых сайтов (чёрный фон, зелёный текст, моноширинный шрифт)
- **Книга гостей**: формы с инсет-рамками, динамическое добавление записей
- **Адаптивность**: боковая панель переходит под контент на узких экранах (< 768px)

## 💬 Книга гостей

Книга гостей позволяет посетителям оставлять сообщения. Сообщения хранятся в памяти приложения (сброс при перезагрузке страницы). Для добавления записи:
1. Перейдите на страницу "Guestbook"
2. Введите имя и сообщение
3. Нажмите "Добавить запись"

## 📊 Счётчик посещений

Отображается на главной странице в стиле старых сайтов (чёрный поле, зелёные цифры, моноширинный шрифт, 6 знаков с ведущими нулями).

## 🔧 Ограничения

1. **Хранение в памяти**: сообщения книги гостей хранятся только в памяти приложения. При перезагрузке страницы все записи сбрасываются. Для постоянного хранения потребуется бэкенд или localStorage.
2. **Без бэкенда**: сайт完全 frontend, нет серверной части.
3. **Счётчик посещений**: увеличивается при каждой загрузке, но сбрасывается при перезагрузке страницы.
