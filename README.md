# 🕰️ Retro Site — персональный сайт в стиле интернета 2000-х

**Retro Site** — персональный сайт, вдохновлённый эпохой раннего интернета и домашними веб-страницами начала 2000-х годов. Проект написан на Rust с использованием Leptos и WebAssembly и размещён на GitHub Pages.

🌐 **Сайт:** https://kamurkin.github.io/retro_site/

## 🎨 Внешний вид

Дизайн сайта передаёт атмосферу старого интернета:

- Голубая, синяя, серебристая и белая цветовая гамма.
- Градиенты, рамки, тени и глянцевые кнопки.
- Пиксельные декоративные элементы.
- Анимации и эффекты при наведении.
- Шрифты в духе Windows XP — MS Sans Serif и Tahoma.
- Панели, таблицы и блоки, характерные для персональных сайтов 2000-х годов.

## 🛠️ Используемые технологии

- **Rust** — основной язык программирования.
- **Leptos 0.5** — UI-фреймворк.
- **WebAssembly** — выполнение приложения в браузере.
- **Trunk** — сборка и запуск проекта.
- **HTML5 и CSS3** — структура и оформление.
- **wasm-bindgen и js-sys** — взаимодействие Rust с браузерными API.
- **GoatCounter** — сбор статистики посещений.
- **GitHub Pages** — публикация сайта.

## 📱 Адаптивность

Сайт поддерживает несколько вариантов компоновки:

- **Смартфоны (до 600 px):** компактный заголовок и перенос навигации.
- **Планшеты (601–900 px):** отдельная адаптивная компоновка с центрированным заголовком и навигацией.
- **Компьютеры (более 900 px):** классический вариант с заголовком слева и навигацией справа.

Вёрстка рассчитана на разные размеры экранов и не должна создавать горизонтальную прокрутку.

## 📄 Страницы сайта

| Страница | Описание |
|---|---|
| **Home** | Главная страница, приветствие и последние обновления |
| **About me** | Информация об авторе, интересах и увлечениях |

Навигация между разделами работает без полной перезагрузки страницы благодаря SPA-архитектуре приложения.

## 📊 Счётчик посещений

На сайте установлен счётчик на основе **GoatCounter**.

Он отображает реальную статистику просмотров страниц, а не случайное или демонстрационное число.

Особенности:

- Стилизованное ретро-табло с чёрным фоном и зелёными цифрами.
- Шесть знаков с ведущими нулями.
- Учёт переходов между разделами сайта без полной перезагрузки.
- Подсчёт просмотров пяти основных маршрутов: `/`, `/about`, `/projects`, `/guestbook` и `/contacts`.
- Отображение общего количества просмотров в табло и боковой панели.

Если статистику не удаётся загрузить, например из-за блокировщика запросов или сетевой ошибки, вместо числа отображаются прочерки. Это не должно мешать работе сайта.

Статистика собирается внешним сервисом GoatCounter. Собственный сервер для этого проекту не требуется.

## 💬 Гостевая книга

На странице Guestbook посетители могут оставлять сообщения.

Чтобы добавить запись:

1. Откройте страницу Guestbook.
2. Введите своё имя.
3. Напишите сообщение.
4. Нажмите кнопку добавления записи.

**Ограничение:** сообщения хранятся в памяти приложения. После перезагрузки страницы они исчезают. Постоянного хранилища или серверной базы данных пока нет.

## 🚀 Запуск проекта локально

### Требования

1. Установленный [Rust](https://rustup.rs/).
2. Целевая платформа WebAssembly:

   ```bash
   rustup target add wasm32-unknown-unknown
   ```

3. Установленный Trunk:

   ```bash
   cargo install trunk
   ```

### Режим разработки

В корневой папке проекта выполните:

```bash
trunk serve
```

После запуска сайт будет доступен по адресу:

http://127.0.0.1:8080

### Сборка проекта

```bash
trunk build --release
```

Готовые файлы появятся в папке `dist/`.

## 🌐 Публикация

Проект размещён на GitHub Pages.

Для автоматической публикации используется GitHub Actions. При отправке изменений в ветку `main` запускается workflow, который:

1. Получает исходный код проекта.
2. Устанавливает Rust и Trunk.
3. Собирает приложение для WebAssembly.
4. Подготавливает файлы для GitHub Pages.
5. Публикует новую версию сайта.

При сборке для GitHub Pages используется путь проекта:

```bash
trunk build --release --public-url /retro_site/
```

## ⚠️ Известные ограничения

- **Гостевая книга:** сообщения не сохраняются после перезагрузки страницы.
- **Отсутствие собственного бэкенда:** приложение работает на стороне браузера.
- **Аналитика:** статистика зависит от доступности GoatCounter и может быть недоступна при блокировке запросов.
- **Счётчик:** данные могут обновляться с задержкой из-за кэширования на стороне сервиса.
