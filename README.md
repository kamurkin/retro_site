# 🕰️ Retro Site — Персональный сайт в стиле интернета 2000-х

Персональный сайт в эстетике раннего интернета (2000–2005 годы), созданный с использованием Rust, Leptos и WebAssembly.

Проект вдохновлён персональными домашними страницами начала 2000-х: яркие панели, градиенты, таблицы, глянцевые кнопки и характерная синяя цветовая гамма.

## 🎨 Внешний вид

Сайт использует визуальный стиль старых персональных веб-страниц:

- Голубая, синяя, серебристая и белая цветовая гамма
- Градиенты, рамки, тени и глянцевые кнопки
- Пиксельные декоративные элементы
- Анимации и эффекты при наведении
- Шрифты в стиле Windows XP (MS Sans Serif / Tahoma)
- Таблицы, панели и блоки, характерные для сайтов начала 2000-х

## 🛠 Технологии

- **Rust** — основной язык программирования
- **Leptos 0.5** — UI-фреймворк
- **WebAssembly** — целевая платформа (`wasm32-unknown-unknown`)
- **Trunk 0.22.1** — сборщик и сервер разработки
- **HTML5 + CSS3** — разметка и оформление
- **wasm-bindgen / js-sys** — взаимодействие с браузерными API из Rust

Внешние CSS-фреймворки и сторонние платные API не используются.

## 🚀 Быстрый старт

### Предварительные требования

1. **Rust** — установите [rustup](https://rustup.rs/).
2. **Цель WebAssembly**:

   ```bash
   rustup target add wasm32-unknown-unknown
   ```

3. **Trunk**:

   ```bash
   cargo install trunk
   ```

### Запуск в режиме разработки

Из корневой папки проекта выполните:

```bash
trunk serve
```

После запуска сайт будет доступен по адресу:

**http://127.0.0.1:8080**

### Сборка для продакшена

```bash
trunk build --release
```

Готовые файлы появятся в папке `dist/`.

## ✨ Особенности

- **Ретро-дизайн** — оформление в духе персональных сайтов начала 2000-х.
- **Навигация** — переключение между основными разделами сайта.
- **Гостевая книга** — добавление сообщений через форму.
- **Счётчик посещений** — стилизованный под старые веб-счётчики.
- **Адаптивная вёрстка** — боковая панель перемещается под основное содержимое на узких экранах (менее 768px).

## 💬 Гостевая книга

Посетители могут оставлять сообщения на странице **Guestbook**.

Чтобы добавить запись:

1. Перейдите на страницу Guestbook.
2. Введите своё имя.
3. Напишите сообщение.
4. Нажмите кнопку добавления записи.

**Важно:** записи хранятся только в памяти приложения. После перезагрузки страницы они исчезают.

## 📊 Счётчик посещений

На главной странице расположен стилизованный счётчик в духе старых сайтов:

- Чёрный фон
- Зелёные цифры
- Моноширинный шрифт
- Шесть знаков с ведущими нулями

Счётчик демонстрационный: его значение не сохраняется между загрузками страницы и не отражает реальное количество посетителей.

## ⚠️ Ограничения

1. **Временное хранение записей:** сообщения гостевой книги хранятся в памяти приложения и сбрасываются после перезагрузки страницы.
2. **Отсутствие бэкенда:** проект работает на стороне браузера и не имеет серверной части.
3. **Демонстрационный счётчик:** значение счётчика не сохраняется и не является реальной статистикой посещений.

Для постоянного хранения сообщений и подсчёта посещений потребуется серверная часть или внешнее хранилище.
